# Data Dictionary

## Purpose

This document describes the fields available in the credit card transaction dataset and defines how each field will be used in the analysis.

## Status

🚧 Initial version — to be completed after reviewing the raw dataset.

## Field Classification

Each field will be classified as:

- **KEEP** — relevant for analysis
- **TRANSFORM** — requires modification or creation of a derived field
- **REMOVE** — not required for the business analysis

## Planned Analysis Areas

The dataset will be reviewed across the following areas:

- Transaction activity
- Merchant activity
- Transaction amount
- Fraud indicators
- Time-based patterns
- Geographic patterns
- Risk indicators
- Financial exposure

## Data Privacy Considerations

Fields that are not required for analysis, particularly direct personal or card identifiers, will not be included in the final analytical dataset or dashboards.
