# Credit Card Risk & Transaction Monitoring

## Project Overview

This project analyzes credit card transaction data to identify fraud patterns, merchant risk, transaction anomalies and potential financial exposure.

The analysis is designed from a business and risk-management perspective, with a focus on transaction monitoring and practical risk controls.

## Business Objective

The objective is to analyze transaction activity and identify:

- Fraud and suspicious transaction patterns
- High-risk merchant categories and merchants
- Transaction trends over time
- Unusual transaction behavior
- Potential financial exposure
- Risk indicators that can support monitoring and control decisions

The final outcome will translate analytical findings into practical business recommendations.

## Dataset

The project uses the Credit Card Fraud Detection dataset created by Sparkov and published by Kartik2112 on Kaggle.

The dataset contains simulated credit card transactions with information including:

- Transaction date and time
- Merchant
- Merchant category
- Transaction amount
- Cardholder location
- Merchant location
- Customer information
- Fraud indicator

The dataset is synthetic and does not represent real banking transactions.

## Key Questions

The analysis will investigate questions such as:

1. How does transaction activity change over time?
2. Which merchant categories show elevated fraud rates?
3. Which merchants have the highest transaction volume and fraud exposure?
4. Does transaction amount relate to fraud risk?
5. Are there specific times or periods associated with higher risk?
6. Does the geographic distance between the cardholder and merchant relate to suspicious activity?
7. Which merchants or transaction patterns should receive enhanced monitoring?
8. What practical controls could help reduce financial exposure?
